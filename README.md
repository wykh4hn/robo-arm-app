# robo-arm-app

Web app to monitor and command an **SO-101** robot arm doing pick-and-place: real-time 3D model, joint position and velocity, trajectories, STOP and command.

- `docs/requirements.md` — what to build (frontend spec)
- `docs/sketch.png` — layout sketch
- `design-system/` — **SO-101 Monitor** design system: tokens, fonts, component styles and previews. Start at `design-system/README.md`; browse every component with `npx serve design-system` and open the page it prints.
- `CLAUDE.md` — how Claude Code should use all of the above

The app itself is not built yet.
