The Lucide icons this interface uses (lucide-static 0.460.0, ISC licence), one file per meaning — see Iconography in the brand book for what each one means. These copies are drawn in the `text` ink (#1f2933) so they preview on light grounds; in the app use `lucide-react` with `currentColor` so icons take the colour of their label (status text tokens, `on-header`, `on-stop`). 24-unit grid, 2px stroke, round caps and joins; render at 16px by default, 14px in tags and steppers, 20px in STOP and banners.
