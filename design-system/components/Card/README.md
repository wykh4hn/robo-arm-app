# Card

The panel every block sits in: white `surface`, 1px `border`, `radius-lg` (8px), no shadow.

**Parts:** `rb-card__head` (title `t-card-title`, optional `rb-card__sub` in `t-caption`/`muted`, actions on the right), `rb-card__body` (16px sides), optional `rb-card__foot` (`border-subtle` top rule, `t-caption`).

**Rules:** cards sit `space-3` (12px) apart on `bg`. One title per card, sentence case. Never add a coloured left border or a shadow to make a card stand out — status lives in chips and banners.
