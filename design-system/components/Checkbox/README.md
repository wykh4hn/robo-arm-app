# Checkbox

Native checkbox (`accent-color: primary`) with a 13px label, used for 3D layer toggles (Bóng lệnh, Vệt đầu kẹp, Quỹ đạo dự kiến, Hệ trục, Tên khớp) and per-joint chart legend toggles.

**Rules:** wrap the input in its `<label>`; group with `role="group"` and an `aria-label`. Toggles change the view instantly — no Apply button. Give each 3D toggle a tooltip.
